# Imágenes propias del Archivo de Panem

Sube aquí tus imágenes con el **nombre exacto** y cada una aparecerá sola en su ficha. Si falta alguna, la web se queda como está.

- Formatos: `.jpg`, `.png`, `.webp` o `.jpeg` (la web prueba los cuatro).
- Para subirlas desde GitHub: entra en la carpeta que toque → **Add file** → **Upload files** → arrastra las imágenes → **Commit changes**.
