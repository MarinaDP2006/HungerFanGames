# Imágenes propias del juego

Sube aquí tus fondos con el **nombre exacto** y saldrán solos en su pantalla, oscurecidos para que se lea el texto. Si falta alguno, se queda el fondo de siempre.

- Formatos: `.jpg`, `.png`, `.webp` o `.jpeg`. Horizontal 16:9.
- Para subirlos desde GitHub: entra en `juego/` → **Add file** → **Upload files** → **Commit changes**. El siguiente APK los lleva dentro.
