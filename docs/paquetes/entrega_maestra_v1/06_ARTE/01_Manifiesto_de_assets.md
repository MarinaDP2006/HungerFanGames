## Requisitos técnicos por asset
- UI: SVG preferido para iconos; PNG/WebP para fondos.
- Retratos: master de alta resolución y derivado recortado.
- Fondos: 16:9 o variante responsive según pantalla.
- Mapas: capas separadas cuando el motor necesite sectores clicables.
- Cada recurso debe incluir alt text y licencia.
- No se permite imitar retratos de actores reales ni recrear fotogramas de películas.
