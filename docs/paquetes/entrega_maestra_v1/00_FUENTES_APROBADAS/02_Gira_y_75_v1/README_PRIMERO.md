# La Cosecha | Producción creativa 02
## Gira de la Victoria y 75.º Vasallaje

**Propósito:** entregar a Claude contenido narrativo y especificaciones de integración. No modificar el 50.º ni añadir acontecimientos a sus ocho eventos existentes.

**Reglas:** canon literario como base; películas como referencia visual cuando no contradigan los libros. Las rutas alternativas deben etiquetarse como tales. Las decisiones del jugador pueden alterar relaciones y resultados, pero no deben cambiar retroactivamente hechos ya establecidos sin una causa narrativa.

**Alcance:** escenas previas, diálogos, decisiones y consecuencias persistentes. No incluye implementación técnica ni escenas nuevas de Arena.
