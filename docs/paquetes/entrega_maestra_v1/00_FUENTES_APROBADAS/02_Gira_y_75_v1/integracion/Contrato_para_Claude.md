# Contrato de integración
- No inventar ni reescribir los textos narrativos aprobados.
- Mantener IDs existentes y crear IDs nuevos solo para escenas previas aquí especificadas.
- No modificar los ocho acontecimientos de Arena del 75.º.
- Guardar variables y decisiones de forma persistente y exportable.
- Entregar pruebas de continuidad Gira → 75.º y de carga de partida.
- Si una escena requiere un dato canónico no confirmado, marcarlo como bloqueo y no improvisar.
