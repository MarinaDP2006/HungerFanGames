# La Cosecha | Web: Archivo de Panem
## Objetivo
La Web es una experiencia independiente para la comunidad de Los Juegos del Hambre: un archivo/compendio navegable. Android conserva el juego completo. La Web no debe cargar el motor de campañas, Arena, guardados ni simulación.

No es una web corporativa ni un producto para sustituir el juego. Es el archivo personal y comunitario del universo del proyecto.
