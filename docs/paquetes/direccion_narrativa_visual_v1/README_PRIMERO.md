# LA COSECHA — Paquete de dirección narrativa y visual

**Versión:** 1.0 de trabajo  
**Fecha:** 27-11-2026  
**Destino:** rama `integracion-cosecha-5x` del repositorio `MarinaDP2006/HungerFanGames`.

## Qué contiene
Este paquete entrega una dirección narrativa y visual unificada para completar La Cosecha:
- Biblia de continuidad y reglas narrativas.
- Diseño de estructura para las campañas 74.º, Gira de la Victoria, 75.º, Rebelión y Guerra.
- Especificación de identidad y pantallas para Modo Historia, Modo Libre y Modo Presidente.
- Modelo de decisiones persistentes, personajes y criterios de aceptación.
- Instrucciones de integración para Claude.

## Estado honesto
Este paquete es una **entrega creativa de diseño y estructura narrativa**, no una afirmación de que el juego completo esté terminado. No contiene una implementación ejecutable, APK, Web funcional, retratos oficiales, música comercial ni pruebas de dispositivo. Las campañas están desarrolladas a nivel de arco, secuencia de escenas, objetivos dramáticos y decisiones estructurales. Los diálogos escena por escena, textos finales de todos los acontecimientos y validación de canon requieren producción y revisión por entregas.

No se deben marcar como terminadas las campañas hasta integrar sus textos, comprobar la continuidad y ejecutar las pruebas correspondientes.

## Reglas de seguridad del repositorio
- No fusionar el PR #1 ni modificar `main` sin aprobación expresa.
- Trabajar únicamente en `integracion-cosecha-5x`.
- No ejecutar scripts de integración narrativa automáticamente.
- No integrar 5.2, 5.3 o 5.4 rechazados.
- No añadir eventos, turnos, crónicas de Arena, encuentros entre rivales ni reacciones a muertes de tributos secundarios en el paquete del 50.º.
- No modificar las campañas 74.º/75.º existentes hasta que el paquete correspondiente esté aprobado.
- No copiar texto de novelas, guiones, letras ni diálogos protegidos.
