# Dirección de arte — identidad de los tres modos

## Principio
Los tres modos comparten tipografía, rejilla, iconografía base, accesibilidad y sistema de navegación. No comparten la misma composición ni el mismo lenguaje visual. La identidad debe cambiar con el propósito de cada modo.

## Modo Historia — «Relato bajo vigilancia»
**Sensación:** cinematográfica, íntima, opresiva y emocional.

- Composición: imagen ambiental dominante, panel narrativo legible, retrato contextual.
- Jerarquía: lugar y momento; personaje; texto; opciones.
- Fondos: específicos por escena y campaña, con capas y desenfoque suave solo detrás de texto.
- Paleta: variable por campaña; Distrito 12 carbón y tierra, Capitolio marfil/dorado/rojo, Rebelión acero y hormigón.
- Interacción: decisiones grandes, legibles, con consecuencias resumidas cuando se descubren.
- Movimiento: transiciones lentas y discretas; respetar reducir movimiento.
- Sonido: ambiente localizado, música por acto, control independiente de volumen.

Pantallas: selector de campaña, prólogo, escena, diálogo, decisión, diario, relaciones, mapa narrativo, resumen de capítulo y finales.

## Modo Libre — «Diseña tus Juegos»
**Sensación:** laboratorio creativo y herramienta de simulación.

- Composición: paneles modulares, vista previa central, inspector lateral.
- Paleta: azul acero, grafito, neutros; acentos configurables.
- Navegación: pasos de configuración con resumen persistente.
- Pantallas: nueva partida, editor de tributos, editor de distritos, editor de Arena, reglas, peligros, recursos, alianzas, patrocinadores, simulación y resumen.
- Cada editor debe incluir validación y vista previa.
- Permitir guardar plantillas y duplicar configuraciones.
- No obligar a rellenar todos los campos; ofrecer valores por defecto explicados.

## Modo Presidente — «El peso del poder»
**Sensación:** institucional, fría, estratégica y tensa.

- Composición: panel de situación, mapa político, indicadores, informes y cola de decisiones.
- Paleta: negro, gris, rojo de alerta, acero y marfil.
- Pantallas: despacho, mapa de Panem, distritos, economía, seguridad, gabinete, crisis, operaciones, informes, cronología y finales.
- Cada decisión debe mostrar coste estimado, incertidumbre, grupos afectados y consecuencias conocidas.
- Las consecuencias desconocidas deben mantenerse ocultas hasta que el juego las revele.

## Sistema común
- Diseño responsive para las resoluciones soportadas.
- Contraste AA como objetivo mínimo para texto normal.
- Navegación por teclado y foco visible.
- Tamaño de texto ajustable.
- Reducir movimiento.
- Audio y volumen persistentes.
- Confirmación para borrar partidas.
- No comunicar estados solo mediante color.
- No usar alert() como interfaz de ajustes.
